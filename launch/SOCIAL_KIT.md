## 1. LinkedIn post (EN / bilingual)

**Launching: UAE Open Intelligence Platform — *All of the UAE's open data, as one intelligence.***

The UAE publishes a lot of open data, but it lives in scattered portals and formats. So we built an Arabic-first, open-source platform that turns it into a single, navigable observatory.

What it is: a unified observatory, analytics, an interactive knowledge graph, and ready-to-use APIs — all server-rendered, no React/Vue/Angular.

Highlights:
- 106 innovation projects · 36 free zones · 12 macro indicators · 28 heritage items · a 6-dataset catalogue (192 records total).
- An interactive force-directed knowledge graph: 209 nodes, 306 edges — zoom, pan, filter.
- 16 REST endpoints under `/api/v1` with a standard `{ok,data,error,meta}` envelope, pagination, filtering, and CSV/JSON exports.
- Arabic-first and RTL-native, bilingual fields, dark + light themes, ⌘K command palette.

Every dataset is source-labelled and confidence-scored — prototype figures are clearly marked. Open source: MIT (code) / CC BY 4.0 (data).

Clone it, run `npm run demo`, explore: https://github.com/<your-org>/uae-open-intelligence

## 5. Short message for tech communities

**EN (Slack / Discord / Reddit / "Show HN"-style):**

> **Show: UAE Open Intelligence Platform — the UAE's open data, unified (Arabic-first, open-source)**
>
> I built an Arabic-first, open-source platform that pulls scattered UAE open data into one server-rendered observatory: 5 datasets (innovation, free zones, AI skills, heritage, macro indicators — 192 records), an interactive force-directed knowledge graph (209 nodes / 306 edges), and 16 REST endpoints under `/api/v1` with CSV/JSON export. The stack is deliberately no-build — Hono + TypeScript, HTMX, Alpine.js, Chart.js, Leaflet, and Node's built-in SQLite — so `git clone` → `npm install` → `npm run demo` gets you running on localhost:3000 with zero native deps. Every dataset is source-labelled and confidence-scored, and prototype/estimate figures are clearly marked. Code is MIT, data is CC BY 4.0 (aggregated from public sources — verify critical figures officially). Feedback, issues, and PRs genuinely welcome: https://github.com/<your-org>/uae-open-intelligence
